# DeluluVerse — Parallel Universe You

> Somewhere, another you already did it.

**Live:** https://deluluverse-nu.vercel.app

![DeluluVerse portal](preview-desktop.png)

DeluluVerse is a cinematic parallel-universe identity simulator. Give it a few facts about your current life and it fractures them into alternate realities: founder-you, 2050-you, the career you never chose, and a neon cyberpunk timeline.

## ✦ Features

- Personalized deterministic reality generation — no API key required
- Four cinematic alternate universes
- Interactive branching decision experiment
- Re-rollable reality seed
- Copyable reality summaries
- Local persistence via `localStorage`
- Responsive fantasy / sci-fi UI
- Reduced-motion accessibility support
- Zero database dependency and zero shared infrastructure

## Stack

- Semantic HTML5
- Modern CSS (responsive layout, gradients, animation, reduced-motion support)
- Vanilla JavaScript
- Browser `localStorage`
- Zero runtime package dependencies

## Run locally

No package installation is required.

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

You can also run the syntax check:

```bash
npm run check
```

## Privacy

Profile answers are stored only in the visitor's browser. DeluluVerse v1 has no authentication, database, analytics, or third-party AI API.

## Deployment

The project is static-host friendly and includes `vercel.json` with defensive response headers.
